# Zhouyue Qian — Personal Website

A responsive, single-page portfolio prepared for GitHub Pages.

## Preview

Open `index.html` in a browser, or serve this folder with any local static-file server.

## Publish with GitHub Pages

1. Create a public repository named `leaddis.github.io` under the GitHub account `leaddis`.
2. Upload everything in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. The site will appear at `https://leaddis.github.io/` after GitHub finishes deploying it.
